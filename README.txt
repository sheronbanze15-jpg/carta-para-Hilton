# Carta para Hilton

Este é o primeiro protótipo do site.

Arquivos:
- index.html — estrutura do site
- style.css — aparência de carta antiga
- script.js — mensagens e navegação
- fotos/ — coloque aqui as fotografias que quiser
- audio/ — coloque aqui um áudio que você tenha autorização para usar

Para testar:
1. Extraia a pasta.
2. Abra o arquivo index.html no navegador.

O site atualmente tem 10 páginas de texto, porque foram fornecidas 10 mensagens.
Podemos depois:
- reduzir para 7 páginas;
- inserir fotos entre as mensagens;
- colocar transições mais elaboradas;
- adicionar um áudio fornecido por você;
- criar uma versão pronta para publicar na internet.
